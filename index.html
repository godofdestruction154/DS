Project Overview

A menu-driven Contact Management System built with a Binary Search Tree (BST) in C. Each contact stores a unique Contact ID, Name, and Phone Number. Contacts are organized in the BST by their unique ID, and an inorder traversal displays them in ascending order of ID.

Data Science C Language BST

Problem Statement

  • Develop a menu-driven Contact Management System using a Binary Search Tree in C.
  • Each contact record contains a Contact ID, Name, and Phone Number.
  • Organize contacts in the BST based on unique contact IDs.
  • Use inorder traversal to display contacts in ascending order of Contact ID.

Features

  • 1. Add a new contact to the BST (IDs must be unique).
  • 2. Search for a contact using its Contact ID.
  • 3. Delete a contact using its Contact ID.
  • 4. Display all contacts in ascending order of Contact ID (inorder traversal).
  • 5. Not-found messages are shown when a contact does not exist.
  • 6. Exit the application.

Algorithm

BST Operations
  1. Create Node: Allocate memory for a new BST node and store the contact (ID, name, phone). Set left and right pointers to NULL.
  2. Insert: If the tree is empty, the new node becomes the root. Otherwise, compare the new contact's ID with the current node's ID — go left if smaller, right if larger. Repeat until an empty spot is found. Reject duplicate IDs.
  3. Search: Start at the root. If the target ID equals the current node's ID, the contact is found. If smaller, search the left subtree; if larger, search the right subtree. If NULL is reached, the contact is not found.
  4. Delete: Find the node. Three cases:
    • Leaf node: simply free the node.
    • One child: replace the node with its child.
    • Two children: replace the node's data with its inorder successor (smallest ID in the right subtree), then delete that successor.
  5. Display (Inorder): Traverse left subtree, visit the root, then traverse the right subtree. This prints contacts in ascending order of Contact ID.
  6. Repeat the menu until the user chooses to exit.

Data Structure

struct Contact {
    int id;          // BST key (unique)
    char name[50];
    char phone[20];
};

struct Node {
    struct Contact data;
    struct Node *left;
    struct Node *right;
};

Invariant: For every node, all IDs in the left subtree are smaller than the node's ID, and all IDs in the right subtree are larger. Inorder traversal (left → root → right) therefore visits contacts in ascending ID order.

Source Code

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

typedef struct {
    int id;
    char name[50];
    char phone[20];
} Contact;

typedef struct Node {
    Contact data;
    struct Node *left, *right;
} Node;

Node* createNode(Contact c) {
    Node *n = (Node*)malloc(sizeof(Node));
    n->data = c; n->left = n->right = NULL;
    return n;
}

Node* insert(Node *root, Contact c) {
    if (root == NULL) return createNode(c);
    if (c.id < root->data.id) root->left = insert(root->left, c);
    else if (c.id > root->data.id) root->right = insert(root->right, c);
    else printf("Duplicate ID %d\\n", c.id);
    return root;
}

Node* search(Node *root, int id) {
    if (root == NULL) return NULL;
    if (id == root->data.id) return root;
    return id < root->data.id
        ? search(root->left, id)
        : search(root->right, id);
}

Node* findMin(Node *root) {
    while (root && root->left) root = root->left;
    return root;
}

Node* deleteNode(Node *root, int id) {
    if (root == NULL) return NULL;
    if (id < root->data.id) root->left = deleteNode(root->left, id);
    else if (id > root->data.id) root->right = deleteNode(root->right, id);
    else {
        if (!root->left && !root->right) { free(root); return NULL; }
        if (!root->left) { Node *t = root->right; free(root); return t; }
        if (!root->right) { Node *t = root->left; free(root); return t; }
        Node *t = findMin(root->right);
        root->data = t->data;
        root->right = deleteNode(root->right, t->data.id);
    }
    return root;
}

void inorder(Node *root) {
    if (root) {
        inorder(root->left);
        printf("ID: %d | %s | %s\\n", root->data.id, root->data.name, root->data.phone);
        inorder(root->right);
    }
}

int main() {
    Node *root = NULL; int choice;
    while (1) {
        /* menu: 1-add, 2-search, 3-delete, 4-display, 5-exit */
        switch (choice) { /* ... see contact_management_system.c ... */ }
    }
    return 0;
}

Beginner's Guide

Complete Beginner's Guide (Start Here if You Are New)

What is this project?

This is a Contact Management System. Think of it like a digital phonebook. You can save your friends' names and phone numbers, look them up later, delete them, and see the whole list sorted by ID number. It is written in the C programming language and uses a Binary Search Tree — a special way of organizing data so it stays sorted and fast to search.

What you will need

  • A computer (Windows, Mac, or Linux)
  • A C compiler (a free tool that turns C code into a running program)
  • About 10 minutes of time

Step 1 — Download the files

Use the download buttons at the top of this page to save:

  1. contact_management_system.c — the actual program code
  2. index.html — this presentation page (optional, for offline viewing)

Step 2 — Install a C compiler

  • Windows: Download and install MinGW or Code::Blocks (it comes with a compiler).
  • Mac: Open Terminal and type xcode-select --install to get the compiler.
  • Linux: Open Terminal and type sudo apt install build-essential.

Step 3 — Save the C file

Put contact_management_system.c inside a folder on your computer. Remember where you saved it (for example: C:\Users\YourName\Documents\CMS or /home/yourname/cms).

Step 4 — Compile the program

Open your command prompt or terminal, go to that folder, and type: 

$ gcc contact_management_system.c -o cms

This tells the compiler: "Take the C file and create a runnable program named cms." If there are no error messages, it worked!

Step 5 — Run the program

$ ./cms

(On Windows, type cms.exe instead.)

A menu will appear. Follow the on-screen numbers:

  • 1 — Add a new contact
  • 2 — Search for a contact by ID
  • 3 — Delete a contact by ID
  • 4 — Show all contacts (sorted by ID)
  • 5 — Exit

Step 6 — Try it out

1. Choose 1 and add a few contacts (give each a unique ID like 101, 102, 103).
2. Choose 4 — you will see them listed in order from smallest ID to largest.
3. Choose 2 and type an ID to find that contact.
4. Choose 3 and type an ID to remove that contact.
5. Choose 5 to quit.

💡 Beginner tip: If you see an error saying gcc: command not found, it means the C compiler is not installed yet. Go back to Step 2 and install it for your computer type.
